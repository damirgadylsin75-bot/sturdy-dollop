# Sturdy Dollop — Outbreak: Tactical City Defense

Horde-defense + тактическая стратегия в реальном времени **с паузой** на схематичной
карте города в стиле геолокационных приложений (весь город и все сущности — точки и
пластины, «живая карта»). Игра строится в **Roblox Studio** через **Rojo**, код живёт
в **GitHub**.

## Суть

Ты смотришь на вымышленный город сверху. Игра заранее показывает, **где начнётся
вспышка инфекции**, и даёт время подготовиться: расставить баррикады, посадить
снайперов на крыши, развернуть безопасную зону и пункты эвакуации. Затем стартует
симуляция: зомби потоком расходятся по улицам и заражают гражданских. В реальном
времени (с паузой и ускорением) ты импровизируешь: вызываешь авиаудары и крылатые
ракеты с линкора.

**Счёт — по спасённым гражданским, а не по убитым зомби.**

### Шесть принципов, зашитых в механику

1. **Две фазы — два ресурса.** «Подготовка» (бюджет 🧱: статичная оборона) против
   «импровизации» (командные очки ⚡: авиация). Выигрывает не тот, у кого больше
   урона, а кто верно распределил бюджет между планом и реакцией.
2. **Враг — поток, а не отряд.** Зомби идут по графу улиц полем расстояний до
   ближайших людей. Геометрия (баррикады, обводка зон) важнее силы юнитов.
3. **Управляй темпом.** Авиаудар ложится **линией вдоль улицы** с интервалом —
   «пунктиром» прореживает толпу, а не выкашивает один сгусток (иначе вся масса
   ломает оборону разом).
4. **Скорость — отдельный ресурс.** Авиаудар приходит через 7 секунд (планируй
   заранее), крылатая ракета с линкора — почти мгновенно (ответ на сгустки,
   которые скапливаются прямо сейчас).
5. **Город — оружие (в развитии).** Баррикады ломаются; архитектура рассчитана
   на снос зданий и распространение огня в будущих версиях.
6. **Ядерка = обмен (в развитии).** Спасая город, уничтожаешь город.

| Инструменты | `1` Зона · `2` Баррикада · `3` Снайпер · `4` Эвакуация · `5` Авиаудар · `6` Ракета |

## Правила раунда

1. **Подготовка (75 с, реального времени).** Бюджет 🧱 140: баррикада 10, снайпер 25,
   безопасная зона 30, доп. эвакуация 20. Видна первая вспышка (красное пульсирующее
   кольцо). Строить можно **только** в этой фазе.
2. **Симуляция.** 4 волны вспышек (0/80/160/240 с), каждая телеграфируется за 12 с.
   Гражданские бегут к эвакуации; укушенные через ~1 с сами становятся зомби.
   Безопасная зона укрывает гражданских и эвакуирует их по 1 человеку / 2.5 с, пока
   держится (600 HP, зомби грызут периметр). Баррикада 300 HP. Снайпер бьёт по
   прямой видимости с крыши. Командные очки ⚡: старт 4, максимум 10, +1 / 5 с.
   Авиаудар ⚡3 · ракета ⚡4. **Авиация убивает и гражданских** — целись аккуратно.
3. **Итоги.** Оценка S/A/B/C/D по доле спасённых (S ≥ 85%). «Играть снова» — новый
   случайный город.

## Запуск

### Вариант A — готовый файл (проще всего)

1. Открой вкладку **Actions** репозитория → последний workflow **CI** → артефакт
   **game-rbxl** → скачай `game.rbxl`.
2. Открой файл в Roblox Studio → **Play**. Всё соберётся само: город генерируется
   кодом при старте.

### Вариант B — Rojo live-sync (для разработки)

```bash
git clone <repo> && cd sturdy-dollop
rojo serve                # нужен Rojo 7.x: ставится с GitHub Releases
```

1. В Studio поставь плагин **Rojo** (CreatorStore / Toolboox → плагины).
2. Подключись к `localhost:34872` — дерево `src/` зальётся в место.
3. **Play**.

### Структура

```
default.project.json      # дерево Rojo: src → DataModel
src/
  shared/                 # ReplicatedStorage.Shared
    config.luau           # весь баланс игры в одном месте
    mapgen.luau           # детерминированный генератор города (сид)
    graph.luau            # граф улиц: Dijkstra, снаппинг
  server/                 # ServerScriptService.Game
    init.server.luau      # бут раунда, фазы, маршрутизация команд
    sim.luau              # фиксированный шаг 1/30, пауза, скорость, планировщик
    city.luau             # сборка визуальной карты из данных
    population.luau       # гражданские + зомби: движение по графу, заражение
    units.luau            # баррикады, снайперы, зона, эвакуация
    strikes.luau          # авиаудар (задержка) и крылатая ракета (мгновенно)
    scoring.luau          # счёт, бюджеты, условия конца
    remotes.luau          # RemoteEvent-ы и маршрутизация
  client/                 # StarterPlayerScripts.GameClient
    init.client.luau      # регенерирует город из сида (данные карты не реплицируются)
    camera.luau           # верхняя камера «навигационного приложения»
    input.luau            # размещение с «призраками» и снапингом
    hud.luau              # HUD: фазы, бюджеты, счёт, итоги
    fx.luau               # взрывы, трассеры, бомбардировщик, ракета
tests/
  harness.mjs             # headless-прогон игровой логики в настоящем Luau (WASM)
  sim_test.luau           # сценарий полного раунда с ассертами
.github/workflows/ci.yml  # Rojo build + luau-compile + симуляция раунда
```

### Как это проверяется без Studio

- **CI** на каждый пуш: собирает `game.rbxl` (артефакт), компилирует все `.luau`
  официальным `luau-compile` и **прогоняет полный раунд игры headless**: настоящий
  Luau (WASM) выполняет серверные модули с заглушками Roblox API — генерация города,
  размещение обороны, волны, заражение, авиаудары, эвакуация, счёт. Также
  прогоняется базовый сценарий «без обороны» — он калибрует сложность.
- Локально: `cd tests && npm install && node harness.mjs ..`

## Архитектурные решения

- **Один авторитет — сервер.** Клиент только показывает «призраки» и шлёт команды;
  сервер валидирует фазу, бюджет, лимиты и геометрию.
- **Детерминированный mapgen.** Сид публикуется в атрибуте `Seed`; клиент
  регенерирует те же данные — карта не реплицируется вообще.
- **Симуляция на фиксированном шаге** (1/30) с планировщиком на игровом времени:
  пауза замораживает всё, включая уже вызванные авиаудары.
- **Зомби — поле, а не маршруты.** Каждые 1.5 с считается Dijkstra-поле от всех
  живых людей; баррикадные рёбра получают штраф ×6 — толпа ищет обход, а если его
  нет, ломает препятствие. Заражённые граждане пополняют орду (снежный ком).
