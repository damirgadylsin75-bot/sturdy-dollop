# Drag 2D — драг-рейсинг в профиль

2D-драг как Pixel Car Racer / Drag Racing Online: вид сбоку, две полосы,
обе машины в кадре. Машина строится нашим кодом: кузов-пластина с картинкой
+ два колеса на мотор-хинжах, физика настоящая (серверная). Концепт:
[CONCEPT.md](CONCEPT.md).

## Управление (клавиши)

- `W` / стрелка вверх — газ; `S` / вниз — тормоз
- `M` — авто/ручная; в ручной `LeftShift` — вверх, `LeftControl` — вниз
- Жми RACE в гараже → дерево старта → на зелёном газ в пол
- Фальстарт (газ до зелёного) = дисквалификация

## Как вставить свои картинки машин

1. Подготовь PNG: кузов машины ВИД СБОКУ (нос влево), и отдельно колесо (круг, вид с торца).
2. В Studio: вид → Asset Manager → кнопка Bulk Import → выбери PNG.
3. Правой кнопкой по картинке → Copy Asset ID (получишь вида rbxassetid://123456).
4. Пришли ID мне в чат (впишу в конфиг) или вставь сам в `src/shared/config.luau`,
   секция `Config.Art` (PlayerBody / PlayerWheel, для ИИ — AIBody / AIWheel).
5. Пока картинок нет — цветные заглушки, у колёс видна спица (видно вращение).

## Инфраструктура (как в первой игре)

- `serve.bat` — Rojo live-sync в Roblox Studio (положи рядом `rojo.exe`)
- CI: синтаксис всех `.luau`, линтер require-графа
- `tools/rbx_cloud.py` + workflow **Remote exec** — запуск кода на настоящих
  серверах Roblox по метке `[remote-exec]` в коммите, отчёт — в комментах PR

Работа: pull → Rojo-синк → Play. Диагностика в три уровня работает.
