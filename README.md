# Drag II — драг-рейсинг без ходьбы

Гараж-экран + заезды на 1/4 мили. Концепт: [CONCEPT.md](CONCEPT.md).

## Как добавить дефолтную машину (Workspace)

1. В Studio: вид → Toolbox (Creator Store) → найди машину на A-Chassis (или свою модель).
2. Перетащи модель машины прямо в Workspace (в 3D-окно). Переименовывать не нужно,
   распаковывать тоже — сервер сам найдёт её по внутреннему модулю «A-Chassis Tune».
3. Жми Play. В Output появится «[CarService] машина захвачена…», копия встанет
   на старт левой полосы, камера покажет трек сбоку. Кнопка RACE пересоздаёт машину.
4. Если машина стоит боком/задом: `Config.Race.CarYawDeg` = 90 / 180 / 270 (config.luau).
5. После stop Play модель в Workspace остаётся как была — перенос в шаблоны живёт
   только внутри сессии. Rojo-синхронизация Workspace не трогает, так что модель
   может жить там постоянно, конфликтов с синком нет.

Если в Output «жду машину» — модель не найдена: значит это не цельная A-Chassis
модель (нет модуля «A-Chassis Tune» внутри). Закинь другую.

## Инфраструктура (как в первой игре)

- `serve.bat` — Rojo live-sync в Roblox Studio (положи рядом `rojo.exe`)
- CI: синтаксис всех `.luau`, линтер require-графа
- `tools/rbx_cloud.py` + workflow **Remote exec** — запуск кода на настоящих
  серверах Roblox по метке `[remote-exec]` в коммите, отчёт — в комментах PR

Работа: pull → Rojo-синк → Play. Диагностика в три уровня работает.
